\section{Introducci\'on}
El procesamiento paralelo de arreglos es una de las aplicaciones fundamentales de la computaci\'on concurrente. En esta pr\'actica se aborda la inversi\'on paralela de los elementos de un arreglo mediante el uso de hilos POSIX (\texttt{pthreads}) en lenguaje C.

\section{Objetivos}
\begin{itemize}
    \item Dise\~nar una estrategia de divisi\'on de datos por bloques disjuntos.
    \item Implementar la inversi\'on concurrente en C con la biblioteca \texttt{pthread.h}.
    \item Demostrar anal\'iticamente que la ejecuci\'on no genera condiciones de carrera ni interbloqueos.
\end{itemize}

\section{Marco Te\'orico}
\subsection{Hilos POSIX (pthreads)}
Los hilos permiten la ejecuci\'on concurrente de m\'ultiples flujos dentro del mismo espacio de direcci\'on de memoria. Para evitar inconsistencias al modificar estructuras compartidas, la memoria asignada a cada hilo debe ser mutuamente excluyente o sincronizada.

\subsection{Divisi\'on por Bloques}
Para un arreglo de tamaño $N$, la inversi\'on solo requiere intercambiar los elementos del rango $i \in [0, \lfloor N/2 \rfloor - 1]$ con los elementos correspondientes $N - 1 - i$. Dividir la primera mitad del arreglo entre $K$ hilos garantiza que ningún hilo acceda a la misma casilla simult\'aneamente.

\section{Ejercicio 2: Invertir un Arreglo en Paralelo}

\subsection{Demostraci\'on de Correctitud}
Sea $A$ un arreglo de tamaño $N$. Sea $M = \lfloor N/2 \rfloor$. Asignamos a cada hilo $j \in \{0, \dots, K-1\}$ un subintervalo continuo $I_j = [start_j, end_j)$ tal que:
\[
\bigcup_{j=0}^{K-1} I_j = [0, M) \quad \text{y} \quad I_a \cap I_b = \emptyset \quad \forall a \neq b
\]
Dado que $I_a \cap I_b = \emptyset$, los hilos acceden a posiciones $i$ e de intercambio $N-1-i$ totalmente disjuntas en cada paso, lo que satisface las Condiciones de Bernstein para la ejecuci\'on concurrente sin bloqueos mutuos.

\subsection{C\'odigo de la Soluci\'on en C}
\begin{lstlisting}[language=C]
#include <stdio.h>
#include <stdlib.h>
#include <pthread.h>

typedef struct {
    int *array;
    int start;
    int end;
    int size;
} ThreadData;

void* reverse_section(void *arg) {
    ThreadData *data = (ThreadData*) arg;
    for (int i = data->start; i < data->end; i++) {
        int target = data->size - 1 - i;
        int temp = data->array[i];
        data->array[i] = data->array[target];
        data->array[target] = temp;
    }
    pthread_exit(NULL);
}

int main() {
    int N = 10;
    int num_threads = 2;
    int *array = malloc(N * sizeof(int));

    for (int i = 0; i < N; i++) array[i] = i + 1;

    pthread_t threads[num_threads];
    ThreadData tdata[num_threads];
    int mid = N / 2;
    int chunk = mid / num_threads;

    for (int i = 0; i < num_threads; i++) {
        tdata[i].array = array;
        tdata[i].size = N;
        tdata[i].start = i * chunk;
        tdata[i].end = (i == num_threads - 1) ? mid : (i + 1) * chunk;
        pthread_create(&threads[i], NULL, reverse_section, &tdata[i]);
    }

    for (int i = 0; i < num_threads; i++) {
        pthread_join(threads[i], NULL);
    }

    printf("Arreglo invertido:\n");
    for (int i = 0; i < N; i++) printf("%d ", array[i]);
    printf("\n");

    free(array);
    return 0;
}
\end{lstlisting}

\section{Conclusi\'on}
La descomposici\'on por datos disjuntos permite paralelizar operaciones sobre arreglos en memoria compartida sin necesidad de mecanismos pesados de sincronizaci\'on (como mutexes), maximizando el rendimiento del procesador.
