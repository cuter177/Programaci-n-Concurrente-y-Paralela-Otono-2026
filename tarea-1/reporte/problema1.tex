\section{Problema 1. Ordenamiento lexicogr\'afico}

\subsection*{Enunciado}
Ordenar lexicogr\'aficamente los elementos de un arreglo de cadenas de forma
ascendente.

\subsection*{An\'alisis del algoritmo}
Se emplea el ordenamiento por transposici\'on par-impar. En cada fase se
comparan e intercambian parejas de elementos adyacentes, alternando el \'indice
de inicio:
\[
    \text{fase par: } S_i = \text{cmp-exch}(i, i+1) \quad \text{para } i = 0, 2, 4, \dots, N-2,
\]
\[
    \text{fase impar: } S_i = \text{cmp-exch}(i, i+1) \quad \text{para } i = 1, 3, 5, \dots, N-2.
\]
Dentro de una misma fase cada pareja toca \'indices disjuntos, por lo que las
tareas son independientes; entre fases existe una dependencia porque una pareja
puede leer un elemento que la fase anterior escribi\'o.

\subsection*{Condiciones de Bernstein}
Para cada tarea se identifican las variables que lee ($L$) y las que escribe
($E$):

\begin{center}
\begin{tabular}{lll}
\toprule
Tarea & Lee $L$ & Escribe $E$ \\
\midrule
T1: \texttt{cmp-exch(A[i],A[i+1])}     & $\{A[i],A[i+1]\}$         & $\{A[i],A[i+1]\}$ \\
T2: \texttt{cmp-exch(A[i+2],A[i+3])}   & $\{A[i+2],A[i+3]\}$       & $\{A[i+2],A[i+3]\}$ \\
\bottomrule
\end{tabular}
\end{center}

Verificaci\'on de independencia:
\begin{itemize}[leftmargin=1.4cm]
    \item \textbf{T1 $\parallel$ T2:} $L(\text{T1}) \cap E(\text{T2}) =
    \emptyset$, $E(\text{T1}) \cap L(\text{T2}) = \emptyset$ y
    $E(\text{T1}) \cap E(\text{T2}) = \emptyset$. Operan sobre \'indices
    disjuntos del arreglo, por lo que las tres condiciones se cumplen y son
    independientes dentro de la misma fase.
    \item \textbf{Fase $k \rightarrow$ fase $k+1$:} existe una dependencia RAW
    porque una tarea de la fase siguiente lee un elemento que una tarea de la
    fase actual escribi\'o. Deben respetar ese orden mediante la barrera
    \texttt{COEND}.
\end{itemize}

\subsection*{Grafo de dependencias}
Para que el grafo sea claro se modela el caso $N = 4$, que generaliza la
estructura para cualquier $N$. Cada nodo $T_{f,i}$ es la comparaci\'on e
intercambio de la pareja $(i, i+1)$ en la fase $f$.

\begin{center}
\begin{tikzpicture}[node distance=1.0cm and 1.3cm]
    \node[wide] (t01) at (0,0)     {T0.1: (0,1)};
    \node[wide] (t02) at (0,-2)    {T0.2: (2,3)};
    \node[wide] (t11) at (2.6,-1)  {T1.1: (1,2)};
    \node[wide] (t21) at (5.2,0)   {T2.1: (0,1)};
    \node[wide] (t22) at (5.2,-2)  {T2.2: (2,3)};
    \node[wide] (t31) at (7.8,-1)  {T3.1: (1,2)};

    \draw[dep] (t01) -- (t11);
    \draw[dep] (t02) -- (t11);
    \draw[dep] (t11) -- (t21);
    \draw[dep] (t11) -- (t22);
    \draw[dep] (t21) -- (t31);
    \draw[dep] (t22) -- (t31);
\end{tikzpicture}
\end{center}

El camino cr\'itico es $T0.1 \rightarrow T1.1 \rightarrow T2.1 \rightarrow
T3.1$ y el paralelismo m\'aximo es $N/2$ en cada fase.

\subsection*{Soluci\'on con COBEGIN--COEND}
\begin{lstlisting}
para fase = 0 .. N-1 hacer
    si fase es par entonces
        COBEGIN
            para i = 0, 2, 4, .., N-2 hacer
                cmp-exch(A[i], A[i+1])
            fin para
        COEND
    sino
        COBEGIN
            para i = 1, 3, 5, .., N-2 hacer
                cmp-exch(A[i], A[i+1])
            fin para
        COEND
    fin si
fin para
\end{lstlisting}

\noindent
Todas las parejas de una misma fase son independientes, por lo que van dentro
del mismo \texttt{COBEGIN}. La barrera \texttt{COEND} garantiza que ninguna
tarea de la fase siguiente comience hasta que todas las de la fase actual hayan
terminado, respetando la dependencia RAW entre fases.
