\section{Problema 1. Ordenamiento lexicográfico}
\subsection{Enunciado}
Ordenar lexicográficamente los elementos de un arreglo de cadenas de forma ascendente.

\subsection{Análisis del algoritmo}
El proceso de ordenamiento lexicográfico ascendente se descompone de la siguiente forma:
\begin{itemize}
    \item \textbf{Fase Par ($\text{fase} \pmod 2 = 0$):} Las comparaciones y posibles intercambios de cadenas se ejecutan en paralelo para los índices pares:
    $$S_i = \text{cmp-exch}(i, i + 1) \quad \text{para } i = 0, 2, 4, \dots, N - 2$$
    \item \textbf{Fase Impar ($\text{fase} \pmod 2 \neq 0$):} Las comparaciones y posibles intercambios se ejecutan en paralelo para los índices impares:
    $$S_i = \text{cmp-exch}(i, i + 1) \quad \text{para } i = 1, 3, 5, \dots, N - 3$$
\end{itemize}
Las operaciones dentro de una misma fase son totalmente independientes entre sí, cumpliendo con las condiciones de Bernstein.

\section{Condiciones de Bernstein}
Para las tareas concurrentes dentro de una misma fase del algoritmo de ordenamiento par-impar, se identifican las variables que lee ($L$) y las que escribe ($E$):

\begin{center}
\begin{tabular}{|l|c|c|}
\hline
\textbf{Tarea} & \textbf{Lee $L$} & \textbf{Escribe $E$} \\ \hline
$T_1$: Comparar e intercambiar $A[i]$ y $A[i + 1]$ & $\{A[i], A[i + 1]\}$ & $\{A[i], A[i + 1]\}$ \\ \hline
$T_2$: Comparar e intercambiar $A[i + 2]$ y $A[i + 3]$ & $\{A[i + 2], A[i + 3]\}$ & $\{A[i + 2], A[i + 3]\}$ \\ \hline
\end{tabular}
\end{center}

\noindent \textbf{Verificación de independencia:} \\
$T_1 \parallel T_2$: $L(T_1) \cap E(T_2) = \emptyset$, $E(T_1) \cap L(T_2) = \emptyset$ y $E(T_1) \cap E(T_2) = \emptyset$. Como operan sobre índices totalmente distintos del arreglo sin solapamiento, las tres condiciones se cumplen. Son independientes y pueden ejecutarse en paralelo bajo el bloque COBEGIN-COEND de la fase.

\section{Solución COBEGIN - COEND}
\begin{lstlisting}[language=C, caption={Pseudocódigo con bloques COBEGIN-COEND}]
PARA fase = 0 HASTA N-1 HACER
    SI fase es PAR ENTONCES
        COBEGIN
            PARA i = 0 HASTA N-2 PASO 2 HACER
                SI paises[i] > paises[i+1] ENTONCES
                    INTERCAMBIAR(paises[i], paises[i+1])
                FIN SI
            FIN PARA
        COEND
    SINO
        COBEGIN
            PARA i = 1 HASTA N-2 PASO 2 HACER
                SI paises[i] > paises[i+1] ENTONCES
                    INTERCAMBIAR(paises[i], paises[i+1])
                FIN SI
            FIN PARA
        COEND
    FIN SI
FIN PARA
\end{lstlisting}

\noindent \textbf{COBEGIN:} Indica el inicio de la región donde las iteraciones del bucle $i$ se ejecutan concurrentemente. \\
\textbf{COEND:} Representado por la barrera de sincronización implícita al final del bloque. Ninguna tarea de la siguiente fase puede comenzar hasta que todas las tareas de la fase actual hayan terminado.

\section{Grafo de dependencias}
Para que el grafo sea visualmente claro y aplicable, se modelará el comportamiento para un subconjunto de $N = 6$ elementos, el cual generaliza perfectamente la estructura para cualquier $N$.

\noindent \textbf{Definición de Tareas (Nodos):} Cada tarea representa la comparación y el intercambio (si es necesario) de dos elementos adyacentes.
\begin{itemize}
    \item \textbf{Fase 0 (Par):} T0.1 (0,1), T0.2 (2,3), T0.3 (4,5)
    \item \textbf{Fase 1 (Impar):} T1.1 (1,2), T1.2 (3,4)
    \item \textbf{Fase 2 (Par):} T2.1 (0,1), T2.2 (2,3), T2.3 (4,5)
    \item \textbf{Fase 3 (Impar):} T3.1 (1,2), T3.2 (3,4)
    \item \textbf{Fase 4 (Par):} T4.1 (0,1), T4.2 (2,3), T4.3 (4,5)
    \item \textbf{Fase 5 (Impar):} T5.1 (1,2), T5.2 (3,4)
\end{itemize}

En cada fase, las tareas son independientes entre sí (paralelismo horizontal). Sin embargo, para pasar a la siguiente fase, una tarea depende de los resultados de las dos tareas adyacentes de la fase anterior. Esto genera el patrón de zigzag visible en las conexiones.

\section{Implementación en C}
\begin{lstlisting}[caption={Ordenamiento par-impar paralelo }, label={lst:ordenpaises}]
#include <stdio.h>
#include <string.h>
#include <omp.h>

#define N 10

int main(void)
{
    char paises[N][30] = {
        "Mexico", "Argentina", "Brasil", "Canada", "Chile",
        "Colombia", "Francia", "Alemania", "Japon", "Peru"
    };
    int fase, i;

    for (fase = 0; fase < N; fase++) {

        if (fase % 2 == 0) {
            /* 
             * COBEGIN (Fase Par) 
             */
            #pragma omp parallel for
            for (i = 0; i < N - 1; i += 2) {
                if (strcmp(paises[i], paises[i + 1]) > 0) {
                    char temp[30];
                    strcpy(temp, paises[i]);
                    strcpy(paises[i], paises[i + 1]);
                    strcpy(paises[i + 1], temp);
                }
            }
            /* COEND */
        } else {
            /* 
             * COBEGIN (Fase Impar) 
             */
            #pragma omp parallel for
            for (i = 1; i < N - 1; i += 2) {
                if (strcmp(paises[i], paises[i + 1]) > 0) {
                    char temp[30];
                    strcpy(temp, paises[i]);
                    strcpy(paises[i], paises[i + 1]);
                    strcpy(paises[i + 1], temp);
                }
            }
            /* COEND */
        }
    }

    printf("Paises ordenados lexicograficamente de forma ascendente:\n");
    for (i = 0; i < N; i++)
        printf("[%d] %s\n", i, paises[i]);

    return 0;
}
\end{lstlisting}
