\section{Problema 2. Invertir un arreglo}

\subsection{Descripción del Problema}
Diseñar e implementar un programa concurrente en lenguaje C que invierta los elementos de un arreglo de enteros de tamaño $N$. La inversión debe realizarse dividiendo el arreglo en bloques distribuidos entre múltiples hilos de ejecución POSIX (\texttt{pthreads}).

\subsection{Demostración de Correctitud}
Sea $A$ un arreglo de tamaño $N$ indexado de $0$ a $N-1$. La inversión del arreglo requiere intercambiar el elemento en la posición $i$ con el elemento en la posición $N - 1 - i$ para todo $0 \le i < \lfloor N/2 \rfloor$.

\begin{proof}
Dividimos el rango de índices $[0, \lfloor N/2 \rfloor - 1]$ en $K$ subintervalos disjuntos $I_j$ asignados a cada hilo $j \in \{0, \dots, K-1\}$. Como $I_a \cap I_b = \emptyset$ para todo $a \neq b$, no existen dos hilos modificando el mismo índice $i$ simultáneamente, garantizando la ausencia de condiciones de carrera sobre los índices de origen. Asimismo, los índices de destino $N - 1 - i$ son únicos y disjuntos entre hilos. Por lo tanto, la ejecución paralela equivale a la permutación simétrica global esperada.
\end{proof}

\subsection{Código en C}
\begin{lstlisting}[language=C]
#include <stdio.h>
#include <stdlib.h>
#include <pthread.h>

typedef struct {
    int *array;
    int start;
    int end;
    int size;
} ThreadData;

void* reverse_section(void *arg) {
    ThreadData *data = (ThreadData*) arg;
    for (int i = data->start; i < data->end; i++) {
        int target = data->size - 1 - i;
        int temp = data->array[i];
        data->array[i] = data->array[target];
        data->array[target] = temp;
    }
    pthread_exit(NULL);
}

int main(int argc, char *argv[]) {
    int N = 10;
    int num_threads = 2;
    int *array = malloc(N * sizeof(int));

    for (int i = 0; i < N; i++) array[i] = i + 1;

    pthread_t threads[num_threads];
    ThreadData tdata[num_threads];
    int mid = N / 2;
    int chunk = mid / num_threads;

    for (int i = 0; i < num_threads; i++) {
        tdata[i].array = array;
        tdata[i].size = N;
        tdata[i].start = i * chunk;
        tdata[i].end = (i == num_threads - 1) ? mid : (i + 1) * chunk;
        pthread_create(&threads[i], NULL, reverse_section, &tdata[i]);
    }

    for (int i = 0; i < num_threads; i++) {
        pthread_join(threads[i], NULL);
    }

    printf("Arreglo invertido:\n");
    for (int i = 0; i < N; i++) printf("%d ", array[i]);
    printf("\n");

    free(array);
    return 0;
}
\end{lstlisting}
